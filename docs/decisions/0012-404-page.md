# Decision 0012: Site-wide 404 page built as `not-found.tsx`

**Date:** October 25, 2026
**Status:** Applied in the working tree, not committed
**Decided by:** Project owner (instruction in the working session)
**Affects:** `src/app/not-found.tsx`, `docs/page-audit.md`, `docs/briefs/404-page-brief.md`
**References:** `docs/26-launch-checklist.md`, `docs/25-quality-assurance-checklist.md`, `docs/16-technical-architecture.md`

## Decision

The 404 page is built as `src/app/not-found.tsx` at the app root and renders inside the root layout.

- **Indexation:** noindex and nofollow through an explicit `robots` metadata entry. No canonical, no JSON-LD, no breadcrumbs.
- **Metadata:** it does not use `buildPageMetadata`, because that helper always emits a canonical.
- **Sitemap:** excluded. `src/app/sitemap.ts` is a hardcoded route list, so the 404 cannot enter it.
- **Copy:** Option B. Label "Error 404", H1 "We can't find that page", a short body, "View Careers" to `/careers/`, "Contact Us" to `/contact/`, and a "Back to the homepage" text link.
- **No service link, by design.** The page points to the two required paths (Careers and Contact) and the homepage only.
- **Secondary label:** "Contact Us" replaces the planned "Discuss a Project". `/contact/` uses the quote-first CTA "Request a Fleet Installation Quote" and the nav label is "Contact", so the planned label matched neither.
- **Buttons:** plain `next/link` elements with the `CtaButton` primary and secondary classes copied locally. They carry no `data-journey` or `data-event`, so a 404 click is not labelled as a recruitment or commercial event. No shared component was added, and there is no hover motion.
- **Analytics:** none.

## Consequences

- The launch and QA checklist item "404 route is useful and links to Careers and Contact" is met in code. The deployed behavior (an unknown URL returns HTTP 404 with the page rendered) still needs a manual Cloudflare preview check.
- If the 404 later needs tracked CTAs, add a dedicated event to `src/lib/analytics/events.ts` rather than reusing a quote or careers event.
